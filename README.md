# OpenVK for iOS

> Нативный клиент OpenVK в атмосфере ВКонтакте 2014–2016 — быстрый, привычный и без лишнего шума.

## Всё важное — на своём месте

- **Лента, профили и сообщества** — записи, фотографии, комментарии, репосты, опросы и реакции.
- **Сообщения** — диалоги, вложения, аудиозаписи, избранное и сохранение истории в кэше.
- **Музыка** — очередь, мини-плеер, тексты, плейлисты и офлайн-загрузки.
- **Видео** — VLC-плеер с перемоткой, поворотом, повторной попыткой и быстрым стартом.
- **Несколько аккаунтов** — OpenVK и VepurOVK, с раздельными сессиями и кэшем.
- **Уведомления** — активность, заявки в друзья и напоминания о днях рождения.

## Сборка

Нужны macOS, Xcode и iOS 15 или новее.

```bash
git clone https://github.com/BassmanOff/OpenVKSwift.git
cd OpenVKSwift
xcodegen generate
open OVK.xcodeproj
```

В Xcode выберите свою команду подписи и запустите приложение на iPhone. Для бесплатного Apple ID подпись действует 7 дней.

<details>
<summary>Что важно знать</summary>

- Токены пользователей хранятся в Keychain.
- Локальные секреты сборки не входят в Git.
- Для видео используется MobileVLCKit: некоторые видео OpenVK содержат MP3 в MP4 и не воспроизводятся стандартным плеером iOS.

</details>

## Статус

Проект активно развивается. Идеи и сообщения об ошибках приветствуются.

OpenVK for iOS не является официальным приложением OpenVK или ВКонтакте.
